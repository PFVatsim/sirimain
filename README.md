# Siri Voice Deck

Voice-controlled app launcher and Discord caller.

## How to Install

1. Download **SiriSetup.exe**
2. Run it
3. Accept the Terms of Service
4. Wait for it to finish cloning
5. Choose your options and click Finish

## Features

- Voice commands (`open Discord`, `call Logan`, etc.)
- Custom apps and contacts
- Discord call support (with calibration)
- Clean dark UI

## Requirements

- Windows 10 or 11
- Microphone
- Internet connection (for voice recognition)
- Git for Windows (the setup will tell you if it's missing)
